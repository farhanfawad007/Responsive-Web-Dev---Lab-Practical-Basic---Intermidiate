## 📖 About This Repository

This repository contains all the practical exercises for the Responsive Web Development lab. It is divided into two main sections:
*   **PART A:** Focuses on core web development concepts, including forms, CSS effects, JavaScript utilities (date/time, browser info), and basic PHP.
*   **PART B:** Focuses on intermediate-to-advanced responsive UI design by cloning popular platforms like Netflix, Amazon, and Flipkart.
